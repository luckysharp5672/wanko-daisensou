# 引き継ぎコードのクラウド保存（Googleスプレッドシート + GAS）

「セーブデータ選択」画面の「他の端末に引き継ぐ」で出てくる引き継ぎコードを、手でコピー＆貼り付けする代わりに、
プレイヤー名をキーにしてGoogleスプレッドシートへ保存・読み込みできるようにする仕組みです。
Google Apps Script（GAS）でスプレッドシートをAPI化し、`web/main.js` からfetchで呼び出します。

未設定の間は何も起きません（ボタン自体が「☁️ プレイヤー名でのクラウド保存は未設定です」という案内に差し替わり、
今まで通りコードを手でコピー/ダウンロードする方法だけが使えます）。

## できること

- 「他の端末に引き継ぐ」を押すと、そのセーブデータのプレイヤー名が自動で入った欄が出るので「クラウドに保存」
- 別の端末の「☁️ プレイヤー名でクラウドから読み込む」欄に同じプレイヤー名を入力して「読み込む」

認証のない素朴な方式です。プレイヤー名を知っていれば誰でも読み書きできるので、**ゲームのセーブデータ以外
（個人情報・パスワードなど）には絶対に使わないでください。** また、同じプレイヤー名で保存すると上書きされるため、
家族内などで名前が重ならないようにしてください（プロフィールの「名前を変更」でいつでも変えられます）。

## セットアップ手順

1. [sheets.google.com](https://sheets.google.com) で新しい空のスプレッドシートを作る（名前は自由、例：「わんこ大戦争 セーブコード」）。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初から入っているコード（`function myFunction() {}` など）を全部消して、このフォルダの [Code.gs](./Code.gs) の中身を貼り付ける。
4. 上部の保存アイコン（💾）でプロジェクトを保存する（プロジェクト名は自由）。
5. 右上の「デプロイ」→「新しいデプロイ」をクリック。
   - 種類の選択（歯車アイコン）で「ウェブアプリ」を選ぶ。
   - 「次のユーザーとして実行」：自分
   - 「アクセスできるユーザー」：**全員**
   - 「デプロイ」をクリック。
6. 初回は権限の承認を求められる（「アクセスを承認」→ 自分のGoogleアカウントを選択 → 「詳細」→「（プロジェクト名）に移動（安全ではないページ）」→「許可」）。これはこのスクリプト自身のスプレッドシートを読み書きする権限で、Googleの審査を受けていない自作スクリプトであるため出る確認です。
7. デプロイ完了後に表示される「ウェブアプリ」のURL（`https://script.google.com/macros/s/＜長い文字列＞/exec` の形）をコピーする。
8. `web/main.js` 内の以下の行を探し、`''` の中に手順7のURLを貼り付ける。

   ```js
   const GAS_SAVE_CODE_API_BASE = ''; // 例: 'https://script.google.com/macros/s/XXXXXXXXXXXX/exec'
   ```

   ```js
   const GAS_SAVE_CODE_API_BASE = 'https://script.google.com/macros/s/XXXXXXXXXXXX/exec';
   ```

9. 保存してゲームを再読み込みすれば、クラウド保存・読み込みの欄が使えるようになる（GitHub Pagesで公開している場合はコミット＆プッシュしてデプロイが反映されるまで待つ）。

## Code.gs を後から修正したとき

Apps Scriptの「保存」だけではウェブアプリのURLの中身は更新されません。修正を反映するには、
「デプロイ」→「デプロイを管理」→ 対象のデプロイの鉛筆アイコン→ バージョンを「新バージョン」にして「デプロイ」を押し直してください
（URL自体は変わりません）。

## データの形（スプレッドシート）

1つ目のシート名は `SaveCodes`。初回アクセス時に自動で作られ、ヘッダー行が入ります。

| key（プレイヤー名） | name（同じくプレイヤー名） | code（引き継ぎコード本体） | updatedAt |
|---|---|---|---|
| たろう | たろう | WANKO1:xxxxxxxx... | 2026-10-11T12:00:00.000Z |

同じプレイヤー名で保存すると、その行が上書きされます（履歴は残りません）。

## API（参考）

- 保存：`POST <ウェブアプリURL>`（`Content-Type: text/plain` でJSON文字列を送る。ブラウザのCORSプリフライトを避けるため）
  - body: `{ "key": "たろう", "name": "たろう", "code": "WANKO1:..." }`
  - 戻り値: `{ "ok": true, "updatedAt": "..." }`
- 読み込み：`GET <ウェブアプリURL>?key=たろう`
  - 戻り値: `{ "ok": true, "key": "たろう", "name": "たろう", "code": "WANKO1:...", "updatedAt": "..." }`
  - 見つからない場合: `{ "ok": false, "error": "not_found" }`
